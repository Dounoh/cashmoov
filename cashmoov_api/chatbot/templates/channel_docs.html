Authentification Assistant / Admin

Le token doit être passé en paramètre d'URL (`?token=`).

Production (WSS) wss://dev-dounoh.xyz/ws/notifications/?token=xxx
Local Dev (WS) ws://localhost:8000/ws/notifications/?token=xxx

1. WebSocket Chat de Groupe

PROD: wss://dev-dounoh.xyz/ws/chat/(room_name)/ DEV: ws://localhost:8000/ws/chat/(room_name)/
Message envoyé par le Client : 
{
"type": "chat.message",
"username": "client",
"groupe_name": "room1",
"message": "Comment recharger mon compte CashMoov ?",
"user_type": "customer"
}
Réponse IA : 
{
"type": "ia.message",
"username": "CashMoov IA",
"message": "Pour recharger, veuillez...",
"user_type": "ia"
}

2. Notifications Admin

PROD: wss://dev-dounoh.xyz/ws/notifications/ DEV: ws://localhost:8000/ws/notifications/ 
{
"type": "notification",
"group_name": "room1",
"count": 4,
"message": "nouveau message de client"
}

3. Présence Assistants

PROD: wss://dev-dounoh.xyz/ws/online/ DEV: ws://localhost:8000/ws/online/ 
{
"type": "online_users",
"count": 2,
"members": ["Moussa", "Fanta"]
}

Logique de traitement

01. NLP

Recherche de réponse via SentenceTransformers (multilingual-e5-base).

02. HUMAIN

Si score de confiance < 0.7, notification envoyée aux admins connectés.

03. REDIS

Gestion des états de présence et des files d'attente en temps réel.
