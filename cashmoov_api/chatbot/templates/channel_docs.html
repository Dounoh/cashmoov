1. WebSocket Chat de Groupe

ws://localhost:8000/ws/chat/group/
Message envoyé par le Client : 
{
                        "type": "chat.message",
                        "username": "client",
                        "groupe_name": "room1",
                        "message": "Comment recharger mon compte CashMoov ?",
                        "user_type": "customer"
                        }

{
                        "type": "ia.message",
                        "username": "CashMoov IA",
                        "groupe_name": "Nom du groupe",
                        "message": "Pour recharger, veuillez...",
                        "user_type": "ia"

{

                        "username": "assistant nom",
                        "groupe_name": "nom group",

                        }

2. Notifications Admin

{
                        "type": "notification.init",
                        "count": 0
                        }
Lorsqu’un message est reçu : 
{
                        "type": "notification",
                        "group_name": "Nom du groupe",
                        "count": 4,
                        "username": "Nom du client",
                        "message": "le message envoyé"
                    }

3. Présence Assistants

ws://localhost:8000/ws/online/

Permet au client de savoir s’il y a des personnes en ligne ou non via Redis.

Format de réponse (Mise à jour en temps réel) : 
{
                    "type": "online_users",
                    "count": 2,
                    "members": ["Moussa", "fanta"],
                    "message": "client est maintenant en ligne"
                    }

Logique de traitement

01.

Résolution IA : Réponse instantanée si une correspondance fiable est trouvée dans la base NLP.

02.

Transfert : Si l'IA échoue, basculement vers le support humain avec notification de transfert à l'utilisateur.

03.

Indisponibilité : Si aucun conseiller n'est dans la liste members, le client reçoit une alerte d'indisponibilité.
